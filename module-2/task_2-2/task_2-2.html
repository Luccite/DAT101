1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. Constants (const) should be used when a value does not change throughout the program. Variables (let) should be used when a value may change, like height for example. Not all values can be constants because some values need to be changed while the program is running.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. Parentheses change the order of operations in an expression. Expressions inside of a parentheses are calculated first, which leads to a different result than it would without the parantheses.

  3. How do we limit floating-point numbers to a given number of decimals?

    4. To limit floating.point numbers to a given number of decimals, we can use the .toFixed() method.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. Because floating-point numbers can have small precision errors, we should compare the difference between them instead of using ===.

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. Comparison operators return a boolean value, which is either true or false. To check whether they are true or false, we can use an if statement.

  6. How does the Math.random() function work, and what can it be used for?

    7. When using Math.random(), it generates a random number between 0 and 1. It can be used for games, simulations, random selections, and generating random numbers within a specific range.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. The modulus operaor(%) returns the remainder after a division. It is useful when calculating leftover values, such as remaining days after a calculating weeks.
